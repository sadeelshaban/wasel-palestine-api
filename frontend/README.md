# 🖥️ Wasel Palestine Frontend

## 📋 **نظرة عامة**

واجهة تفاعلية لعرض وإختبار منصة Wasel Palestine API، مصممة لتقديم المشروع بشكل احترافي وواضح.

## 🚀 **المميزات**

### **📊 عرض المشروع:**
- نظرة عامة على المشروع مع إحصائيات
- عرض كل الـ 47 endpoints بشكل منظم
- حالة النظام (API متصلة)

### **🔐 اختبار المصادقة:**
- اختبار تسجيل الدخول
- اختبار إنشاء حساب جديد
- اختبار استعادة كلمة المرور

### **🗺️ الخريطة التفاعلية:**
- إضافة حواجز على الخريطة
- إضافة حوادث على الخريطة
- عرض البيانات الجغرافية بشكل مباشر

### **📢 اختبار الميزات:**
- اختبار إنشاء البلاغات
- اختبار الاشتراك في الإشعارات
- عرض النتائج مباشرة

### **📈 الإحصائيات الحية:**
- مخطط دائري للـ endpoints
- مخطط أعمدة لحالة المشروع
- تحديث مباشر للبيانات

## 🛠️ **التثبيت والتشغيل**

### **المتطلبات:**
- Node.js 18+ (لـ live-server)
- متصفح حديث (Chrome, Firefox, Safari)

### **التشغيل:**
```bash
# الدخول لمجلد الـ frontend
cd frontend

# تثبيت الاعتماديات
npm install

# تشغيل الخادم المحلي
npm run dev

# الخادم يشتغل على
# http://localhost:3001
```

### **الخيارات الأخرى:**
```bash
# تشغيل على بورت 8080
npm run serve

# بناء الملفات الثابتة
npm run build
```

## 🔗 **الربط مع الـ API**

### **الإعدادات:**
```javascript
// في ملف index.html
const API_BASE = 'http://localhost:3000/api/v1';
```

### **نقاط النهاية المستخدمة:**
- `POST /auth/login` ← اختبار تسجيل الدخول
- `POST /auth/register` ← اختبار إنشاء حساب
- `POST /checkpoints` ← إضافة حاجز
- `POST /incidents` ← إضافة حادث
- `POST /reports` ← إنشاء بلاغ
- `POST /alerts/subscribe` ← اشتراك إشعارات
- `GET /external/weather` ← بيانات الطقس
